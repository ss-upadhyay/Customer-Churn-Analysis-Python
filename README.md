# Customer Churn Analysis - Python

Exploratory data analysis project using Python to understand customer churn patterns and identify factors associated with customer attrition.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Overview

This project explores customer data through data cleaning, exploratory analysis, visualisations, correlation analysis, and comparisons across customer characteristics to understand churn patterns.

## Dataset

This project uses the `Churn_Modelling.csv` dataset.

The dataset can be downloaded from Kaggle:

1. Visit Kaggle and search for **Churn Modelling Dataset**.
2. Download the dataset.
3. Place `Churn_Modelling.csv` in the same folder as the Jupyter Notebook.
4. Run the notebook.

> Note: This repository does not include the dataset. Please download it separately from Kaggle before running the notebook.
